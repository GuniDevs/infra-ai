# infra-ai

Two small Python projects for testing the Infra AI GitHub App. Open a pull request that touches either folder and watch the run appear in Infra AI.

| Folder | What it is |
|---|---|
| `task-tracker/` | FastAPI + SQLite task tracker with filters, paging and stats. |
| `wordstats/` | A tiny word-counting library. |

Each folder has its own README and tests (`python -m pytest`).
